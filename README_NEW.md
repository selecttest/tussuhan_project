# LINE Bot 記帳指令說明(新版)

> 兩人分帳記帳 Bot,資料寫入 Google Sheets。
> 設計原則:**最常用的指令最短、語意自然、手機輸入友善**。

---

## 🚀 快速上手

只要記住一句話:**「品項 + 金額」就能記帳**。

```
拉亞 415
```

Bot 會自動:
- 推測類別(拉亞 → Food)
- 預設 T 付全額
- 寫入今日日期
- 回覆本月累計

其他情境再學就好。

---

## 📝 記帳指令

### 1. 極簡模式(最常用)

**語法**:`[品項] [金額]`

```
拉亞 415
coco 99
尿布 1099
早餐+便當 230
```

| 欄位 | 寫入值 |
|---|---|
| Date | 今日 |
| Type | 由 Bot 自動推測 |
| Detail | 品項文字 |
| Amount | 金額 |
| Payer | T |
| T_paid | 金額 |
| F_paid | 0 |

> 💡 多個品項用 `+` 連接,例如 `早餐+便當+飲料`。

---

### 2. F 付款

**語法**:`F [品項] [金額]`

```
F coco 99
F 聚餐 600
```

| 欄位 | 寫入值 |
|---|---|
| Payer | F |
| T_paid | 0 |
| F_paid | 金額 |

> 💡 只要在最前面加上 `F`,就代表 F 結帳付全額。

---

### 3. 指定分帳金額

**語法**:`[品項] [金額] 分[對方負擔金額]`

`分[X]` 一律代表「**對方負擔 X**」,跟誰結帳無關。

```
早餐+便當 590 分215      ← T 付 590,F 負擔 215
F 聚餐 600 分300          ← F 付 600,T 負擔 300
```

| 情境 | Payer | T_paid | F_paid |
|---|---|---|---|
| `早餐+便當 590 分215` | T | 375 | 215 |
| `F 聚餐 600 分300` | F | 300 | 300 |

> 💡 規則記法:**「分」後面的金額,永遠是另一個人要負擔的金額**。

---

### 4. 手動指定類別

當 Bot 猜錯或猜不到時,把類別放最前面:

```
餐費 拉亞 415
Drink 手搖杯 65
Baby 副食品 280
Other 大創 118
```

> 💡 中文別名(如「餐費」「飲料」)會自動對應到英文分類。

---

### 5. 📅 日期補記(非當天記帳)

當你想補記昨天或更早的帳目,**在最前面加上日期**即可,其餘語法不變。

**支援的日期格式**:

| 寫法 | 範例 | 對應日期 |
|---|---|---|
| 相對日期 | `昨天` / `前天` | 昨天 / 前天 |
| 月/日 | `5/7` | 今年 5 月 7 日 |
| 年/月/日 | `2026/5/7` | 完整日期 |

**範例**:

```
昨天 拉亞 415
前天 F coco 99
5/7 火鍋 600 分300
2026/5/6 Baby 尿布 1099
5/7 F 聚餐 600 分300
```

> ⚠️ 補記日期不能是**未來**,且建議不超過 30 天前以避免誤輸入。
> 💡 日期一定要放在**最前面**,Bot 才會識別為補記。

---

## 🔔 記帳後回饋

每次成功記帳,Bot 會回覆**確認資訊 + 該月累計**,讓你隨時掌握花費進度。

**範例回覆**:

```
✅ 已記錄
📅 5/8  Food  拉亞  $415  (T付)

📊 本月累計
   T   $12,340
   F   $ 2,100
   合計 $14,440
```

**分帳記錄的回覆**:

```
✅ 已記錄
📅 5/8  Food  早餐+便當  $590  (T付)
   └ T 負擔 $375 / F 負擔 $215

📊 本月累計
   T   $12,715
   F   $ 2,315
   合計 $15,030
```

**日期補記的回覆**(會額外標註補記日期,且累計顯示「補記日期所屬月份」):

```
✅ 已記錄(補記 5/7)
📅 5/7  Food  拉亞  $415  (T付)

📊 5月累計
   T   $11,925
   F   $ 1,885
   合計 $13,810
```

> 💡 累計金額會即時計算「補記日期所屬月份」的總額,方便確認補記的月份是否正確。

## 🔍 查詢指令

| 指令 | 功能 |
|---|---|
| `查` | 本月支出摘要 + 結算(誰欠誰) |
| `今日` | 今日所有明細 |
| `昨天` | 昨天所有明細 |
| `本月` | 等同於 `查` |
| `查 4月` 或 `查 2026-04` | 指定月份摘要 |
| `查 餐費` | 本月該類別小計 |
| `最近` 或 `最近5` | 最近 5 筆紀錄 |
| `結算` | 本月誰該補誰多少 |
| `help` / `說明` | 顯示指令清單 |

### 結算邏輯

每筆紀錄的「公平負擔」= `Amount / 2`
- T 多付的 = `T_paid - Amount / 2`
- F 多付的 = `F_paid - Amount / 2`

最終加總得出淨額,例如:

> 📊 本月結算
> T 共付 $12,340 / F 共付 $2,100
> ➡️ F 應補 T **$5,120**

## ✏️ 編輯指令

| 指令 | 功能 |
|---|---|
| `刪` 或 `撤銷` | 刪除自己最後一筆,回覆被刪除的內容 |
| `改金額 [新金額]` | 修改最後一筆的金額 |
| `改類別 [新類別]` | 修改最後一筆的類別 |

```
刪
→ ✅ 已刪除:5/8 Food 拉亞 $415
```

> ⚠️ 為了安全只允許刪除「最後一筆」,避免誤刪歷史紀錄。

## 🏷️ 類別對照表

Bot 會根據關鍵字自動推測類別。輸入中文別名也會對應到英文分類。

| 輸入關鍵字 | 對應分類 | 自動推測關鍵字(範例) |
|---|---|---|
| 餐費 / 食物 / 早餐 / 午餐 / 晚餐 | **Food** | 拉亞、便當、火鍋、麵、鴨肉、M、咖啡廳 |
| 飲料 / 喝 | **Drink** | coco、手搖、茶詠春、天仁茗茶 |
| 寶寶 / 嬰兒 / 育兒 | **Baby** | 尿布、奶粉、米餅、副食品、健保 |
| 學費 / 補習 | **Tuition** | 學費、補習、課程 |
| 保險 | **Insurance** | 保險、保費 |
| 其他 | **Other** | 大創、雜支 |

> 💡 推測不到時,Bot 會用 LINE Quick Reply 按鈕讓你一鍵選擇,免打字。

## ✅ 注意事項

- 每個欄位以**空白**分隔;品項可用 `+` 連接多個品名(如 `早餐+便當`)。
- 金額只接受**正整數**,不含小數點。
- 記帳日期預設為**今日**;若要補記,**日期一定要放在最前面**。
- 分帳金額**不可大於**總金額。
- 類別大小寫由 Bot 自動正規化(`food` → `Food`)。
- 輸入錯誤格式時,Bot 會回覆錯誤說明並提示正確語法。

## 🎯 設計原則

1. **最常用的指令最短** — 直接打「品項 金額」就能記帳。
2. **語法一致** — `分[X]` 永遠代表「對方負擔 X」,沒有方向性混淆。
3. **彈性補記** — 支援昨天、前天、特定日期,符合實際生活情境。
4. **即時回饋** — 每次記帳都顯示該月累計,進度一目了然。
5. **手機友善** — 減少特殊字元、減少切換鍵盤次數。
6. **容錯設計** — 類別自動推測、Quick Reply 按鈕、明確的錯誤提示。

## 📊 資料結構(Google Sheets)

| 欄位 | 說明 |
|---|---|
| Date | 記帳日期(今日或補記日期) |
| Type | 分類(Food / Drink / Baby / Tuition / Insurance / Other) |
| Detail | 品項描述(可用 `+` 連接) |
| Amount | 總金額 |
| Payer | 結帳者(T / F) |
| T_paid | T 實際支付金額 |
| F_paid | F 實際支付金額 |

> 💡 `T_paid + F_paid = Amount`,恆等式成立。

## 🔄 解析優先順序(供開發參考)

Bot 解析訊息時,token 順序大致為:

```
[日期]? [類別]? [F]? [品項] [金額] [分X]?
```

各 token 的判定規則:

1. **日期**: 第一個 token 是 `昨天` / `前天` / `M/D` / `YYYY/M/D` 模式
2. **類別**: 下一個 token 是已知分類關鍵字(中英皆可)
3. **F 付款**: 下一個 token 是 `F`(大小寫皆可)
4. **品項**: 不含空白的字串,可用 `+` 連接
5. **金額**: 正整數
6. **分帳**: `分` 後接正整數,代表對方負擔金額
